Common questions

Merge PDF FAQs

Is this really free?
Yes — there's no signup, no watermark, no page limit and no hidden paywall. The tool runs entirely in your browser, so there's no server cost on our end to pass on to you.
Are my PDFs uploaded anywhere?
No. The merge happens entirely on your device using JavaScript in your browser. Your files are never sent to Nexsia or any third party — closing the tab is the same as deleting them.
Is there a file size or file count limit?
No hard limit, though very large or numerous PDFs will take longer since your device is doing the work instead of a server. For most use cases — combining a handful of documents — merging is near-instant.
Does this work on my phone?
Yes — you can select PDFs directly from your phone's files app, reorder them, and merge, all from the mobile browser.
Can I merge password-protected PDFs?
Not currently — encrypted or password-protected PDFs need to be unlocked first before they can be merged. Unprotected PDFs of any other kind work fine.
Will the page order match what I see on screen?
Yes — drag the files into the order you want before merging. Each source document's own internal page order is preserved; only the order of the documents themselves changes.
