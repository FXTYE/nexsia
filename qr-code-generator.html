Common questions

QR Code Generator FAQs

Is this really free?
Yes — there's no signup, no watermark and no limit on how many codes you generate. It runs entirely in your browser, so there's no server cost on our end to pass on to you.
Do these QR codes expire?
No. This generates a static QR code that encodes your text or link directly — there's no server-side redirect involved, so it will keep working for as long as the destination link itself works. It never "expires" on our end because we're not hosting anything.
Is my text or link uploaded anywhere?
No. The QR code is generated entirely on your device using JavaScript in your browser. Nothing is sent to Nexsia or any third party.
What error-correction level should I use?
Medium (15%) is a good default for most uses. Use a higher level (Quartile or High) if the code will be printed small, placed somewhere it might get scuffed or partially obscured, or if you plan to add a logo on top. Higher error correction makes the code slightly denser for the same content.
PNG or SVG — which should I download?
PNG is the simplest choice for most uses (social posts, docs, printing at the size shown). SVG is a vector format, so it stays crisp at any size — better if you're placing it on a poster, banner or anything printed large.
Is there a limit on how much text I can encode?
QR codes can hold up to a few thousand characters depending on the error-correction level, but codes built from very long text become dense and harder to scan reliably. For anything you want people to actually scan, a short URL or a few hundred characters works best.
