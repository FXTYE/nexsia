Common questions

Image Resizer FAQs

Is this really free?
Yes — there's no signup, no watermark, no file limit and no hidden paywall. The tool runs entirely in your browser, so there's no server cost on our end to pass on to you.
Are my images uploaded anywhere?
No. Resizing happens entirely on your device using JavaScript in your browser. Your files are never sent to Nexsia or any third party — closing the tab is the same as deleting them.
What happens if I resize multiple images with different aspect ratios?
With pixel mode and the lock on, each image keeps its own aspect ratio — the width you enter is applied to every image and the height is calculated per image. With the lock off, every image is stretched to the exact width and height you enter, which can distort images with a different original ratio.
Can I resize an image to be bigger than the original?
Yes — percent mode accepts values above 100%, and pixel mode accepts any dimensions larger than the original. Keep in mind that enlarging a photo doesn't add detail that wasn't there, so very large upscales can look soft or blurry.
Is there a file size or file count limit?
No hard limit, though very large batches of high-resolution photos will take longer since your device is doing the work instead of a server.
