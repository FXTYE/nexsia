Common questions

Split PDF FAQs

Is this really free?
Yes — there's no signup, no watermark, no page limit and no hidden paywall. The tool runs entirely in your browser, so there's no server cost on our end to pass on to you.
Is my PDF uploaded anywhere?
No. Splitting happens entirely on your device using JavaScript in your browser. Your file is never sent to Nexsia or any third party — closing the tab is the same as deleting it.
Can I get multiple separate files out of one PDF?
This tool extracts one selection into one new PDF per run. To get several separate files (e.g. pages 1-5 in one file and 6-10 in another), run the tool again with a different selection each time.
Does this work with password-protected PDFs?
No — a password-protected PDF can't be read by the browser to generate thumbnails or extract pages. Remove the password using your PDF viewer first, then use this tool.
Will the quality or formatting change?
No. Pages are copied directly from the original PDF's internal structure, not re-rendered as images, so text stays selectable and quality is identical to the source.
